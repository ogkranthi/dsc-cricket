## DSC season archive

The 2026 archive reads the reviewed, public cricket fields in
`src/data/season-2026.json`. To refresh a season, import the team's summary,
per-competition player totals and reviewed match results into a snapshot; do not
commit original workbooks. Keep gameplay dates and scorecards separate when
they aren't supplied. Reconcile total completed/abandoned counts and each
competition's results before publishing a win–loss record. For 2026, the T10
Blast outcomes and combined record are left out pending that reconciliation.

Run `npm run build` before publishing. The existing main-branch workflow
deploys the static export to Cloudflare Pages.
